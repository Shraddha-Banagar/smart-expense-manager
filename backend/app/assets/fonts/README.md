# Bundled fonts

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are used by the PDF report
generator because reportlab's built-in fonts (Helvetica etc.) have no glyph
for the Indian Rupee sign (₹) and would render it as a black box.

DejaVu fonts are free to redistribute under the Bitstream Vera / DejaVu
license (see https://dejavu-fonts.github.io/License.html).
